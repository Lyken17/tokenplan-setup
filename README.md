# SoruxGPT API Examples

Minimal Python examples for calling SoruxGPT-hosted GPT and Claude models via the OpenAI Python SDK, plus local Codex CLI setup notes.

## Environment Variables

Set the tokens before running examples:

```bash
export SORUXGPT_GPT_AUTH_TOKEN=<your-gpt-token>
export SORUXGPT_CLAUDE_AUTH_TOKEN=<your-claude-token>
```
